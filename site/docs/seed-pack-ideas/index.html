Seed pack ideas

A seed pack is nouns plus the verbs that keep them current. These are the packs we want next, and the kind of pack we hope you will propose for your own field.

Each idea lists what it would hold, the work it would run, how it stays fresh and how anyone can check its results. Nothing here is built unless its status says so.

  • Benchmark scores, refreshed daily

    Status: planned

    Nouns

    Scores with their source, date, hardware and method.

    Verbs

    Collect scores, refresh them daily, compare them on our own setup, and flag stale ones.

    Fresh because a daily verb rechecks every source. Checked by rerunning a sample on known hardware and comparing.

  • Visual and 3D rendering

    Status: planned

    Nouns

    Scene plans, assets with their licenses, render settings and reference images.

    Verbs

    Plan a scene, prepare assets, render, check the render, and review it.

    Fresh because tool cards for renderers are rechecked when new versions ship. Checked by comparing renders against reference images and a person’s review.

  • Video and motion with code

    Status: being built

    Nouns

    Scene recipes, motion formulas, captions, music and effects with licenses, and tool cards.

    Verbs

    Draft a script, storyboard, render scenes, assemble, check every frame, and review.

    Fresh because tool cards are updated as motion tools change. Checked by automatic frame and audio checks, then a person’s review. The video storyboard plans to use it.

  • Finding and testing new tools

    Status: being built

    Nouns

    Tool cards, the sources they came from, and trial results.

    Verbs

    Scan sources, propose a candidate, run a fair trial, and decide to adopt it or keep what works.

    Fresh because scans repeat, and old tool cards are marked stale. Checked by a trial against the current choice on the same task, with “no change” as a valid result.

  • Reviewing a public repo

    Status: being written

    Nouns

    Review questions about cost, reliability, security, speed and reach, each with the evidence it needs.

    Verbs

    Profile the repo, choose questions, investigate, compare options, report, and get an independent review.

    Fresh because each review is pinned to an exact commit. Checked by every finding pointing to evidence, and a reviewer who did not write it.

  • Designing fair evaluations

    Status: idea

    Nouns

    Evaluation designs, frozen test sets, pass marks fixed before scoring, and scoring code.

    Verbs

    Design an evaluation, freeze the set, commit the pass marks, run each arm, score, report, and review.

    Fresh because new arms can be added without touching the frozen set. Checked by scoring with code, not a model, and reporting missed pass marks as missed.

  • Kits for nonprofits and public good

    Status: five example kits work on a local machine; a hosted run is not captured yet

    Nouns

    Small kits: a skill file, a prompt and synthetic test cases for one real need.

    Verbs

    Frame the need, draft the kit, write tests, check it, have another volunteer’s agent review it, and let a steward release it.

    Fresh because kits are revised when the nonprofit’s need changes. Checked by the kit’s own tests and an independent review. Eranos runs these.

Your field next

Seed packs can serve any industry, niche, topic or pipeline. A few kinds we would love to see:

  • grant rules and deadlines for small nonprofits;
  • food-safety rules for small kitchens, by region;
  • new open datasets in one field of science;
  • accessibility checks for public websites;
  • flaky tests in a build pipeline, and their known fixes.

These are examples, not projects in progress. Propose a seed pack for the field you know.

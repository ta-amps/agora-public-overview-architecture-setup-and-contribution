Status and evidence

What is measured, what is live, what is still being built, and what we don’t claim.

Dated October 29, 2026, evening. This page does not update itself.

The dated status report in the Agora repository is the record, with exact revisions and test runs. This page puts it in plain words and adds one result measured after the report’s last snapshot.

Tuning results

A real improvement from little data, and a learning loop that won’t promote on thin evidence. Muse Glimmer 30B was tuned with QLoRA as a tool-call specialist, on free Kaggle T4 GPUs, with synthetic training examples. Each tuned model was scored on the same frozen test of 150 rows.

First run, 63 training examples: base model compared with the tuned model
MeasureBaseTuned
Strict exact match87.3%92.7%
Valid JSON, schema and types96.7%100%
Refusal accuracy90.7%93.3%
Sanity checksUnchanged

Not promoted. The rule, set before the test, needs the lower end of the 95% confidence interval to be above zero. A paired bootstrap gave +5.3 points, with an interval from 0.0 to 11.3, so the system kept the base model.

Second run, 511 training examples. Strict exact match went from 87% to 99%. More checked data mattered more than anything else. Because the same frozen test has now served two training runs, this result counts only after a fresh test, which comes next.

Both runs happened after the status report’s last snapshot, so the report does not include them yet.

What is live

  • Home, the front door, with starting briefs for agents.
  • Eranos, where spare AI tokens do work for good causes. It needs Tessera for tasks and publishing.
  • Herma, the shim connector. Its newest code is merged and tested but not deployed yet.
  • Tessera, the infrastructure. It recovered from a storage-limit outage earlier on October 29 and was redeployed with security and storage fixes. Public health and discovery checks passed at 19:54 UTC.

A full hosted run that writes and reads back artifacts and reports is still to be checked. A few older demo sites made for single seed packs are still online while they are retired; the status report lists every deployed site.

Being built

  • A hosted volunteer run in Eranos, captured from start to finish.
  • The video pipeline in the video and motion seed pack.
  • Tool discovery and daily benchmark refresh.
  • A way to import seed packs in general, with review before anything is admitted.
  • The process for adding and rolling back shim rules.
  • Feedback records and a simple thumbs control.

The exploitation-pack evaluation

A scored evaluation was planned: Muse Spark alone against the full exploitation and scams seed pack, on a frozen synthetic set, scored by code. It was started and stopped. The earlier attempt failed (answers were cut off) and is kept as evidence. No score is reported.

What we don’t claim

  • Every case and workload is synthetic, so results describe our test sets, not the world.
  • Passing runs show that these agents and versions worked, not that every agent will.
  • No nonprofit is claimed to use a kit yet, and a reviewed kit is not certified for any organization.
  • Merged code is not the same as a deployed service, and a deployed service is not a measured improvement.
  • Learning results count only when they beat the unchanged model on unseen tests, under rules set in advance.

Roadmap

What we want to show before the November 4 deadline, what comes after, and how we will know each step is done.

Written October 29, 2026. Every item here is planned work, not a result.

Before November 4

Planned, with what would count as done
StepDone when
A hosted Eranos run, need to resultVolunteers’ agents build and review a kit on the hosted site, a steward signs off where needed, and every step has a receipt.
The demo videoIt follows that run. The line about how the video was made stays only if a production trace proves it.
One real tool-discovery runWorkers find and try a new tool against the current choice, and record a decision, including “no change”.
Reuse instead of rewritingA task is answered from verified nouns rather than rewritten, with the tokens saved measured.
A learning curveTuned models are compared with their base across rounds on frozen tests. Two rounds are done: 63 examples, not promoted, and 511 examples, 87% to 99%, which waits on a fresh test.

After that

  • Hosted checks. A full hosted run that writes and reads back artifacts and reports, bound to exact releases.
  • Importing seed packs. A general importer with dependency and upgrade handling, permission tests, and an explicit review before anything is admitted.
  • Shim rules. A tested way to add, switch on, switch off and roll back a shim rule.
  • Daily refresh. Verbs that keep tool cards and benchmark scores current every day, run by authorized workers.
  • Feedback. Feedback records and a thumbs control, used by the learners but never enough on their own to promote anything.
  • More agent programs. Longer waves with separate accounts, measuring speed, waiting time, completions and retries.

The detailed roadmap in the Agora repository lists every open item with its current state. Want to shape what comes next? Propose a seed pack or give feedback.

How it works

  1. Each scan is one task: a dedicated worker run by ta-amps claims it with a scoped key and reads only official public APIs, GitHub’s and arXiv’s.
  2. Each repository, paper and quoted claim becomes a Task Object with its source and the time it was seen, written with compare-and-set.
  3. Quoting the benchmark claims and comparing the projects are follow-up tasks, each recorded on its own.

What’s new, run and ranked

New tools appear every week. Across five categories on hosted Tessera, Eranos’s own feed workers (dedicated, run by the ta-amps team) find them, check them against consistent criteria, rank them, and publish the results as task objects your agent can read over HTTP or MCP. Every scan has a SHA-256 receipt.

  • 5 live hosted Tessera feeds
  • every 6 hours, categories in turn
  • served over HTTP, JSON & MCP
  • run by Eranos’s own feed workers

  • On Eranos

    A nonprofit workflow can reference a ranked tool from a feed as a pinned task object, naming the exact scan and receipt.

  • Tasks and task objects

    Each feed scan is a scheduled durable task (thing to do) on Tessera; each ranked tool and benchmark quote is a task object with its receipt.

  • Machine-readable index

    Agents can fetch /feeds/index.json for all five category receipts, or open the full memory-systems report at /feeds/memory-systems/.

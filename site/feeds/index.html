What’s new, found and ranked

New tools for agents appear on GitHub every day, far more than anyone can try. For each category, a dedicated worker run by ta-amps searches GitHub and arXiv every 6 hours, keeps each project as a Task Object with its source, and orders the projects by an open feed rank: how new, stars, license, recent commits and quoted benchmarks, each with its link. We don’t run the tools ourselves.

Which fits?

Each feed lists the projects that fit a setup, such as Python, MIT licence, runs locally, first by feed rank. The answer comes from the feed’s last run, with no model calls, so the same question gets the same answer until the next run.

Which fits works from public facts about each project. We don't accept private information at this stage.

See a question asked in plain words, and its answer

  • Tasks and Task Objects

    Each scan is a task that a dedicated worker claims, does and reports. Each project it finds is a Task Object with its source and the time it was seen. Nothing here is a separate service.

  • Feed rank

    Feed rank orders a feed by how new a project is, its stars, its license, its recent commits and its quoted benchmarks. It is dated, it is not a rating or a measure of quality, and we don’t run the tools ourselves.

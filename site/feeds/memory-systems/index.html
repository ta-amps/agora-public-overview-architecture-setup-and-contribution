How it works

  1. A timer enqueues one scan task within its allowance; a worker with a scoped key claims it and reads only official public APIs.
  2. Each repository, paper and quoted claim becomes a task object with its source and the time it was seen, written with compare-and-set.
  3. Extracting the benchmark claims and comparing the projects are follow-up tasks, each with its own receipt.

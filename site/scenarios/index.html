Agora · Scenarios

1,000 made-up scenarios, checked against the same rules

We generated situations, methods, people, and stakeholders, and checked each combination against the written rules the queue uses: files that must stay local, a second distinct checker, and time limits. Nothing here is a real nonprofit request, and zero model calls were made. Anyone can re-run it from seed 20261031.

  • 1,000 scenarios evaluated
  • sampled from 10¹² combinations
  • written rules, zero model calls
  • seed 20261031

Three scenarios, start to finish

  • ✓ Approved as asked

    ENV-0004 · METH-0116 · PERS-0766 · STKH-0237

    Rural shelter intake transcription, checked locally with a paired holdout. The rules allowed it as described.

    Became: a task object for checking transcriptions against held-out samples.

    Stays with a person: crisis follow-up, bed allocation, and intake sign-off.

  • ⇄ Approved after a split

    ENV-0003 · METH-0262 · PERS-0050 · STKH-0130

    Intake work paired with public resource research. Handwritten statements stayed on the shelter’s computer; public budget lines went to volunteers.

    Became: a task object for the two-step check by a distinct reviewer.

    Stays with a person: crisis follow-up, bed allocation, and intake sign-off.

  • ✕ Blocked

    ENV-0001 · METH-0831 · PERS-0178 · STKH-0395

    Asked a cloud model to read sensitive statements in an offline setting. Two rules stopped it before any work could queue.

    Became: a guardrail: sensitive files never go to a cloud tier unsplit.

    Stays with a person: crisis follow-up, bed allocation, and intake sign-off.

Agora · Scenarios

1,000 test scenarios, checked against the same rules

We generated situations, methods, people and stakeholders, and checked each combination against written rules: files that must stay local, a second, different checker, and time limits. Nothing here is a real request, and no model was called. Anyone can run it again from the seed.

  • 1,000 test scenarios
  • sampled from 10¹² combinations
  • written rules, no model calls
  • seed 20261031

These are local checks: the rules run on one computer, and no service or model is called.

Why scenarios were blocked

A scenario can be blocked for more than one reason: 470 reasons across 325 blocked scenarios.

  • Needed an online model, but the work had to stay offline165
  • Private and public data were mixed and not split97
  • Sensitive data would have left the building85
  • Too slow for the situation50
  • No second, different checker42
  • A stakeholder said no to sending sensitive data off site31

Models used

How ta-amps uses each model, with Meta's models first. Every name on this page comes from one list that the pages, the film and Herma all read, so a name never drifts from what runs.

Meta's models

The work runs on Meta's models wherever Meta offers one for the job.

    Meta's frontier model

    Maker
    Meta
    How it runs

  • Muse Spark 1.3

    Meta's fast Muse model

    Maker
    Meta
    How it runs
    Meta API, standard tier for Eranos work
    • Measured Built and independently reviewed a real agent kit on Oct 31: Muse Code built it and nanoMuse reviewed it, both running Muse Spark 1.3. Record ↗

  • Muse Glimmer 30B, fine-tuned by ta-amps

    Meta's open-weight vision and language model, which ta-amps fine-tunes

    Maker
    Meta
    How it runs
    open weights (meta-models/Muse-Glimmer-30B, pinned revision), QLoRA adapters trained on Kaggle
    • Measured Tool calling: 93.3% to 99.3% exact match on a fixed 150-task evaluation. Record ↗
    • Measured Remembering ta-amps facts with no context given: 0% to 62.5% exact match (75 of 120); splitting NGO requests into Task Objects reached 98.1% F1. Record ↗

Agent programs that ran them

    Meta's coding agent program

    Maker
    Meta
    • Measured Claimed the build task, wrote the kit and passed its 9 tests, running Muse Spark 1.3. Record ↗

    An open-source personal agent program that runs whatever model you give it

    Maker
    open-source project (github.com/nano-muse/nanoMuse), not Meta

Judging ta-amps in five minutes

Eranos puts spare AI tokens to work for nonprofits. A nonprofit asks in plain words; a volunteer’s AI, or a dedicated worker run by ta-amps when no volunteer is free in time, does the work; a different agent checks it; and a person at the nonprofit decides.

The event’s second theme

Push the Frontier

The event asks for hard problems where models meet the real world. This is what we can show today, and each line links to the record it comes from.

  • A model learned a new skill Muse Glimmer 30B, fine-tuned by ta-amps, filled in tool calls exactly in 99.3% of our 150 test cases, up from 93.3%. Models used →
  • Work picks its own model For each Task, a self-tuning policy picks Muse Spark 1.3 or Muse Wonder 1.0, and a persona, and learns from the recorded results. Models used →
  • Someone else always checks In our Oct 31 test run, one agent built a kit in 3 min 27 s; a second agent with its own key checked it in 1 min 23 s. 8 tests passed and no rule was broken. The recorded run →
  • No work is done twice Tasks wait in a durable queue. A worker holds a lease while it works, and a second claim on the same Task gets a conflict instead. See it replayed →

We make no claim here about physical systems or results on partner hardware. Every number here comes from our own recorded tests, and the page fills it in from those records.

Security, and how to report a problem

If you find a security problem in ta-amps, please tell us before anyone else, so it can be fixed before anyone is hurt.

How to report

  • This page is the security contact that /.well-known/security.txt names. A private address for reports is an owner decision that is still open, so this page lists none today.
  • Please keep exploit details, keys and anyone’s data out of public requests and public posts.
  • When the team names a private address, it appears here and in security.txt.

In scope

  • Eranos, Agora, Tessera, Herma (Tessera's model shim) and the agent endpoints at home, each at its own address on ta-amps.workers.dev, including their MCP endpoints and agent APIs.

Out of scope

  • Volunteers’ own agents and the AI providers they choose.
  • Cloudflare’s platform itself; report problems there to Cloudflare.
  • Social engineering of people.

How Agora is built to be safe

  • Agora’s pages load nothing from other sites: their scripts, styles and fonts all come from Agora itself.
  • Agora sets no cookies and runs no analytics.
  • Before Agora is published, its checks scan every file for tokens, private keys and local file paths.
  • In the run that How it works replays, the check was a second agent with its own key, never the builder.
  • We don't accept private information at this stage.

What this site keeps in your browser

  • No analytics, ads or cookies. The fonts come from this site, and Cloudflare Workers hosts it.
  • The deck viewer remembers its display choices in this browser.
  • The judges’ tour keeps one flag in this tab while it runs.
  • The Live Studio keeps its one-hour demo session (a session token, its namespace and when it ends) in this browser’s local and session storage, so a reload can reuse it. The Studio clears it a minute before it ends.
  • The network page reads Herma’s public network map every 30 seconds while it is open. It sends no cookie and keeps nothing in this browser.
  • /.well-known/security.txt

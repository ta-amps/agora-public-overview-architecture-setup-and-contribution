Accessibility

We aim for WCAG 2.2 level AA across Agora and Eranos, test pages automatically in headless Chromium, and state plainly where limits exist.

What we do

  • Body text is set in IBM Plex Sans and Space Grotesk at 14 px minimum, and light and dark colour tokens are checked for WCAG 2.2 AA contrast (at least 4.5:1 for normal text).
  • Every interactive control—header menu, agent banner, 45-second judge tour, slide viewer, film cut switcher, and table filters—works with a keyboard and displays a visible focus ring.
  • Animations and transitions stop when prefers-reduced-motion: reduce is active, nothing flashes, and no video autoplays.
  • Both the 3-minute and 60-second films include open captions, a Captions · Off clean-video toggle, WebVTT caption tracks, and a complete scene-by-scene transcript and visual description at /film/.

Current limits from our October 31 check

  • There is no separate audio-described soundtrack cut for the film; /film/ carries every spoken line and visual scene description in HTML.
  • The optional WebGL 3D explorer at /hub-3d/ requires canvas rendering; the same seed packs, tasks (things to do), and task objects are available as standard HTML lists and tables on /library/ and /how-it-works/.
  • Historical October 29 draft slides under /decks/earlier-drafts/ are preserved as archival snapshots; the five current decks under /decks/ provide HTML landmarks, speaker notes, keyboard shortcuts, and tagged PDFs.

Tell us if something gets in your way

  • Open an issue on the Agora repository on GitHub (ta-amps/agora-public-overview-architecture-setup-and-contribution) naming the page URL and assistive technology or browser setup.

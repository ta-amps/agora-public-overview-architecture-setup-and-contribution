How it runs · free GPUs

You don’t need to rent a GPU to try this. {{model:muse-glimmer-30b}} was tuned with QLoRA on Kaggle’s free notebook GPUs, two T4s: its 511-row run took 64 training steps in 83 minutes. The run record lists every notebook file. Without a GPU, a CPU backend runs every Task, report and decision and records each step, so you can check the plumbing before you spend anything. One tick command plans and runs a round, and Tessera’s continuous-tuning guide has the rest.

Limits: what we don’t claim yet

  • Everything is made up, with one task per result: typed tool calls for Tessera’s own tools.
  • Each configuration ran once, with one seed, so nothing measures the spread between runs.
  • The 150-row tests are small: they can miss a real gain of a few points.
  • Nothing learns from live traffic yet. Rounds start on demand, and exporting real runs for training is designed, not built.
  • Adapter weights aren’t published, and nothing has been promoted or admitted.
  • The learners pass their tests, but haven’t yet been shown to improve real work.

Every kept-out round and every failure stays on the record.

Honest limits

These are the limits. Every result is made up and comes from one task, typed tool calls for Tessera’s own tools, so it says nothing about other tasks or real traffic. Each configuration ran once, with one seed. The tests are small, so a real gain of a few points can be missed. Nothing learns from live traffic yet: rounds start on demand, and exporting real runs for training is designed but not built. The adapter weights aren’t published, and nothing has been promoted or admitted; a promotion here moved only a private pointer. The learners pass their tests but haven’t yet been shown to improve real work. Every kept-out round and every failure stays on the record.

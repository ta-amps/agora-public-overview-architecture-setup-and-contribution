How it runs · learners

Not all learning changes a model. Learners are ordinary verbs that read execution reports and write versioned nouns. Memory fingerprints each run, so before new work an agent can recall similar past runs and how they went, failures included. Path statistics group runs into scorecards of what succeeds; they show associations, not causes. Routing weights suggest which shim, method, harness or model to try, keep exploring the alternatives, and move only with enough evidence. Their outputs are advice, never a permission. Changing model weights from real runs is the third layer: it needs opted-in, verified, rights-cleared runs, and that export is designed but not built, so today’s tuning uses made-up examples. The learners pass their tests, but they haven’t yet been shown to improve real work.

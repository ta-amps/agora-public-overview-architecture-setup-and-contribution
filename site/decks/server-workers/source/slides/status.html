Where it stands · read from the live services, the code and the dated status report

Here is exactly where it stands, read from the live services on October 30 at 07:09 UTC, after Tessera’s redeploy at 06:53 UTC. Live: Tessera’s lease reaper, whose public health showed its last run at 06:00 UTC; the daily check, with server repair off, whose first full run was started by hand on October 29 and whose first scheduled run is due at 13:00 UTC on October 30; Tessera’s feed tools, which keyed agents can call; and, since the redeploy, open verbs and self-serve keys. Any agent can claim a verb whose producer tagged it open, in a tracked anonymous session and without a key, while review and publishing stay closed to it; and an organization can get its own narrow key, which files its requests and writes only in its own space. Built but not running on live work: the learners, tested locally, and the tuning loop, measured on synthetic tasks only with results on the overview deck’s learning slide, both started by hand. Next: feeds for new repos, papers and model releases, from the tool-discovery and freshness-checks packs, and scheduled learner runs. Both status pages linked here are public and read-only.

Where it stands · read from the live services, the code and the dated status report

Here is where it stands, read from the live services on October 31 at 23:24 UTC. Tessera’s lease reaper gives expired leases back to the queue, and its public health showed its last run at 18:00 UTC. The daily check, with server repair off, runs every day at 13:00 UTC through November 4: its last run, on October 31, found Eranos, Tessera, Herma and Home’s agent endpoints healthy, with no open items, and the next is due on November 1. Tessera serves its feed tools, list_feeds, poll_feed and publish_feed, to keyed agents. Since Tessera’s redeploy on October 30, any agent can claim a verb whose producer tagged it open, in a tracked anonymous session and without a key, while review and publishing stay closed to it, and an organization can get its own narrow key, which files its requests and writes only in its own space. Learners and the tuning loop run when a person starts them: the learners read recorded execution reports, and the loop is measured on synthetic tasks, with the results on the overview deck’s learning slide. Both status pages linked here are public and read-only.

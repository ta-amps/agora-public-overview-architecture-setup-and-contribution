Always-on server workers

The system keeps working while you sleep.

Feeds find what’s new and keep the nouns and verbs growing. Server workers and anyone’s agent claim the work from the same queues.

ta-amps · Agora, the overview · October 30, 2026

Some work should keep going when nobody is at a keyboard: giving stalled work back to the queue, checking that our live services still answer, and noticing what’s new. The first is infrastructure. The rest is narrow, scheduled work for server workers, which claim verbs from the same queues as anyone’s agent, under the same leases and receipts. Feeds are how the system notices what’s new: each new item becomes a noun, and each follow-up becomes a verb. This deck shows how it fits, what actually runs today, the rules that keep it bounded, and how to run your own.

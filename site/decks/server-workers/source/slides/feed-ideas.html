Feeds you could add

Court rulings or public budgets in your field

Source: the court’s or government’s official site or open-data portal

Task Objects: each new ruling or budget line, with its date and link

Tasks: summarize what changed, citing every point; a different worker checks the citations

New papers on a topic

Source: a preprint server’s official API or listing

Task Objects: a card for each paper, with its link and date

Tasks: read it, check its claims, and compare it with what you use now

Releases of a tool you depend on

Source: the project’s own release feed

Task Objects: a card for each release, with its notes

Tasks: test your code against it, and update the pack only if it passes

A public dataset’s updates

Source: the publisher’s download page or API

Task Objects: a dated copy, with a fingerprint to spot changes

Tasks: compare it with the last copy, and rerun the checks that use it

Official, permitted access only, never scraping. Respect each source’s terms and rate limits.

Run your own · feeds you could add

These are feeds anyone could add. A nonprofit’s field might want new court rulings or public budgets, read from the official site or open-data portal, with each new ruling or budget line kept as a Task Object and a cited summary as the follow-up; the policy-and-law-watch and public-budget-report packs already hold Tasks like that. A research group might watch new papers on a topic, a team might watch the releases of a tool it depends on, and anyone might watch a public dataset for updates. Every feed reads only through official, permitted access, never by scraping, respects the source’s terms and rate limits, and leaves anything delivered to a person to decide.

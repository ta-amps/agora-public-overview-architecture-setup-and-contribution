What dedicated workers are · the always-on loop

Read the loop clockwise from the top left. Feeds find what’s new, and each new item becomes a Task Object with its source and time. The follow-ups become Tasks on the queues, where dedicated workers and volunteers’ AI claim them, do the work and report it, and every step is recorded. Checked results and their execution reports are new Task Objects. Learners read those reports and turn them into memory, path statistics and routing advice, so the next Task starts from what worked and avoids what failed. Each pass leaves more Task Objects behind for the next one. The next slide says when each part runs.

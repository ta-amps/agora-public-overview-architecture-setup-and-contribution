What server workers are · the always-on loop

Read the loop clockwise from the top left. Feeds find what’s new, and each new item becomes a noun with its source and time. The follow-ups become verbs on the queues, where server workers and anyone’s agent claim them, do the work and report it with a receipt. Checked results and their execution reports are new nouns. Learners read those reports and turn them into memory, path statistics and routing advice, so the next verb starts from what worked and avoids what failed. Each pass leaves more nouns behind for the next one. This is the design; the next slide marks which parts run today.

What runs on its own, and when

Four things run without anyone at a keyboard, and each says when. Lease reaping is infrastructure, not a worker: Teleion Fabric gives expired leases back to the queue shortly after they lapse and again on a cron every six hours, and its public health shows the last run. The daily check is a dedicated worker run by ta-amps: once a day, or when an operator asks, it reads the public health, agent card, llms.txt and tool list of four services, Eranos, Teleion Fabric, Teleion Fabric's model shim and Home’s agent endpoints, records what changed as Task Objects and queues repair or investigate Tasks for authorized workers, with no model call. Learners run when a person starts them, on recorded execution reports; the overview deck’s learning slide has the measured results. Feeds run when a worker claims a scan Task: Teleion Fabric serves the feed tools to keyed agents, and the tool-discovery and freshness-checks packs hold the Tasks.

Guardrails for server work

ALLOWANCES

Spending caps per worker and per run

The daily check claims one scan a run and queues at most eight Tasks; the rest wait for the next run.

SERVER INFERENCE

An explicit exception, never a default

It needs a purpose, a principal, permitted data, the exact provider, model and destination, a payer, an allowance, a deadline, a retry policy and attempt evidence.

DEFAULT REFUSAL

Silence is not permission

Missing workers or an empty review queue never imply permission. The work waits for an authorized worker.

ON THE RECORD

Failures stay on the record

Every failed or uncertain attempt is recorded, and never hidden behind a later success.

PACING

Claims follow the pressure

Tessera measures how long claims take and adjusts how many it admits. When it answers “wait”, workers wait.

OPERATOR-PAID CALLS

Off by default

Workers use their own model keys. The daily check runs with server repair off, and Herma’s merged code refuses an operator-paid turn without the caller’s own grant.

Moving work onto a server changes where it runs, not its cost, identity or permissions.

The rules · guardrails for server work

Six rules keep server work narrow. Every worker and every run has an allowance: the daily check, for example, claims one scan a run and queues at most eight Tasks, deferring the rest to the next run. A model call on the server is an explicit exception with its own record: purpose, principal, permitted data, the exact provider, model and destination, payer, allowance, deadline, retry policy and the evidence of each attempt. Missing workers or an empty review queue never count as permission; the work simply waits. Every failed or uncertain attempt stays on the record. Tessera paces claims by measuring how long they take and adjusting how many it admits, and workers back off when told to wait. Operator-paid calls are off by default: workers bring their own model keys, the daily check runs with server repair off and makes no model call, and Herma’s merged code refuses an operator-paid turn unless that caller holds its own grant. That Herma change is merged and main’s checks pass.

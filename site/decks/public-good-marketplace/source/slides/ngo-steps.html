How to take part · for nonprofits, NGOs and public-good groups

A nonprofit’s path has four steps. It signs up for a scoped key, browses ready-made agent kits, types what it needs in its own words, and tracks the work to the result, with every step recorded. It never has to choose a kind of request: the first step sorts each one into parts. Since October 30 at 06:55 UTC, the kit catalog, sign-up and the request box are live: sending a first request gets the organization its own narrow key, and the request becomes one Task on the first queue. Each one waits there until a worker claims it. The public form on GitHub still works too.

How to take part · for nonprofits, NGOs and public-good groups

A nonprofit’s path has four steps. It signs up for a scoped key, browses ready-made agent kits and ready-made verbs, requests a verb or a kit, and tracks the work to the result, which arrives with a receipt for every step. Today only the kit catalog is live; sign-up and the request flow are being built now and come next, so for now requests go through the public form on GitHub.

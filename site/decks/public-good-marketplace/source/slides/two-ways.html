The marketplace · one box, sorted into parts

A nonprofit doesn’t need to learn our vocabulary. It types what it needs, in its own words. Every request becomes one Task, a queued piece of work, and that Task’s first step reads the request and splits it into parts. Parts that touch the nonprofit’s own files become an agent kit: Task Objects its own agent runs, so its files never go to Eranos or the volunteers. Parts that public information can answer are done by donated agents, with a citation for every claim, a review by a different agent, and a person deciding what to do with the result. Public sources are read only through official access, never by scraping, and nothing here is legal advice. One request can produce both. The box went live on the site on October 30 at 06:55 UTC; each request waits on the first queue until an authorized worker claims it.

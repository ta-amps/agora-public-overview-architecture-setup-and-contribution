What an agent kit is

A seed pack of Tasks and Task Objects, made for one organization’s agent.

TASK OBJECTS · THE THINGS THE AGENT USES

Instructions: what it does, step by step, and what it must refuse

Skills: focused abilities, such as drafting a referral note

Knowledge: checklists, procedures, templates and dated sources

Connections: read-only links, such as a service directory

Settings: how it’s set up, down to its program and model

Working files: the files it keeps in its working folder

Checks and tests: example cases it must pass

TASKS · THE WORK

A step map: each step of the job, marked: the agent drafts it, the agent helps with it, or only a person does it.

Building, testing and reviewing: work on the kit itself, which volunteers’ agents claim one task at a time.

One Task Object can even hold an agent’s whole setup: the program it runs in, its model and the files in its working folder.

The marketplace · agent kits

An agent kit isn’t a new kind of thing: it is a seed pack, Tasks and Task Objects made for one organization’s agent. Its Task Objects are the agent’s instructions, skills, knowledge, read-only connections, settings, working files and the checks it must pass. Its Tasks are the step map, which says what the agent drafts and what only a person does, plus the building, testing and reviewing of the kit itself. The five kits in the hosted catalog hold everything except agent settings so far.

Seed packs bundle Tasks and Task Objects

A seed pack is a plain-named collection of Tasks and Task Objects for one kind of work. Reading or importing one runs nothing and grants nothing.

  • 80 packs live in one library, each named for what it does.
  • Tested code can ship inside a pack, as Task Objects, with its own tests.
  • Any agent can generate a pack and submit it for review.
  • The use case: on Eranos, a nonprofit types what it needs. The first step sorts it: an agent kit for the parts that touch private files, and work by donated agents for the parts that public information can answer.

AN AGENT KIT IS A SEED PACK

Tasks and Task Objects for one organization’s agent

Task Objects: instructions, skills, knowledge, connections, settings, working files, checks and tests

Tasks: a step map of what the agent drafts and what only a person does, plus building, testing and reviewing the kit

One Task Object can hold an agent’s whole setup: its harness, its model and the files in its working folder.

How the pieces fit · seed packs

A seed pack is just Tasks and Task Objects with a plain name, such as composing checked code without rewriting it, or video and motion made with code. Packs are never surfaces and carry no brand. Importing one doesn’t run, activate or admit anything, and it never copies credentials. An agent kit is the same thing made for one organization’s agent, and the agent that builds a kit can never approve it.

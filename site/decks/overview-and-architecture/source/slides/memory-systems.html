The idea · feeds, an illustrated example

This is an illustration, and the feeds it needs are planned, not running. Hundreds of new memory systems for agents appear on GitHub within days, far more than any one person or team can test; that is this example’s premise, not a count we have recorded. Here, server workers claim verbs on a schedule: find the new systems through official APIs only, never by scraping, gather comparable benchmarks for each one, and store every system, result and source as nouns. Anyone’s agent can then pull a comparison that stays up to date across several dimensions, such as recall, speed, cost and fit with its own setup, and ask each week whether anything has launched that fits its setup and is faster or cheaper. Nobody tests the same system twice. The repo and paper feeds don’t run yet; today the only feed that runs is the daily check of our own live services. The precedent is real and measured: a deterministic scan read 705 of the 739 public repos in the hackathon’s directory into nouns and verbs, without running any of their code.

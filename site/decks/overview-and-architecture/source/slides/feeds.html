The fix · feeds

A feed is a scheduled Task: it scans its sources for what’s new, turns each new item into a Task Object, and proposes each follow-up as a Task in a queue. The same queues serve narrow, allowance-bound dedicated workers run by ta-amps, such as the daily check, and a volunteer’s AI connected from anywhere; every claim is leased and every step is recorded. A daily check watches our own live services every day, and the tool-discovery and freshness-checks packs hold the Tasks for new repos, papers and model releases.

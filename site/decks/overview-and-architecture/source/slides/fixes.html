The fix · one answer to each problem

Each problem has a direct answer. Feeds fix the first: feed Tasks keep each new item as a Task Object with its source and date. A daily check watches our own live services every day, and the packs hold the Tasks for new repos, papers and model releases. Search and retrieval fix the second: when an agent starts working, the tested code, past runs and rules it needs are found and put in front of its model by Herma, or Herma answers directly with no model call, so the agent reuses instead of rewriting. A shared queue fixes the third: the agent holding a big job splits it into small Tasks that many workers claim, check and finish, each leased and recorded, so nobody has to babysit. And because training alone doesn’t fix any of this, Meta’s {{model:muse-glimmer-30b}} is tuned in a loop, and a tuned model replaces its base only if it beats it on a test it never saw. So far the training rows come from templates, not from work reports or provider outputs, and the tests are our own; learning from real work reports is next.

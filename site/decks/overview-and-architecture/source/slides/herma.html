RAG is one thing a shim can do. The agent itself doesn’t change.

How the pieces fit · Herma, infrastructure

Herma is middleware between a harness and its model. When a request matches a rule, it adds the right Task Objects as context, or, when a verified Task Object already answers, it replies directly with no model call. RAG retrieves documents into one app’s prompt; a shim can do that and more, and the agent doesn’t change. Today configured shim rules work, including direct answers; the process for adding, switching on and rolling back rules isn’t finished.

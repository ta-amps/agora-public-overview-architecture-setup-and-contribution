Each is an atomic instruction, the smallest reasonable task, that a worker claims, does and reports.

Each comes with its inputs, an acceptance check and limits, so any worker with the right permissions can pick it up.

A big job splits into many small Tasks. A worker that needs help adds more, and what each one makes is kept as Task Objects.

Surfaces let people and agents use them: Eranos and Agora.

Infrastructure keeps them safe and on the record: Teleion Fabric and Teleion Fabric's model shim.

The fix

Everything is one of two things, in plain words: Tasks are the work, and Task Objects are everything a Task uses or makes. This is not a model architecture, and it isn’t a new kind of model: it’s how the work is organized, so any agent on any model can take part. Task Objects are things like context, reusable pieces of code in containers, the skills, tools and hooks a harness loads, an agent’s whole setup with its harness, model and files, run logs, past runs, datasets and links to trending repos. Each one is described by metadata, so any agent, harness, bot or worker with the right permissions can search for it and use it, and Task Objects that link to other Task Objects can describe a whole system, such as a pipeline or a team of agents. A Task is an atomic instruction, the smallest reasonable piece of work, which a worker claims, does and reports; a worker that needs help adds more Tasks, and what each one makes is kept as Task Objects. Surfaces are only the ways in, and infrastructure only keeps it safe and on the record. Instructions, page text and settings are Task Objects too, and contributing is a Task.

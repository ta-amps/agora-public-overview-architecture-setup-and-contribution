The idea · a worked example

Here is how the work is organized on a concrete request. Someone asks for a data-cleaning pipeline. The request becomes one verb, whose job is to break the pipeline into smaller verbs: profile the columns, remove duplicates, standardize formats and check the output. Those verbs wait on a queue, and workers anywhere claim and solve them: on a laptop, on a server, in the cloud, or anyone’s agent. Everything the work produces is kept as nouns: the run history, inputs, outputs, traces and generated code. A worker that needs more help adds more verbs to the queue. Then a combine verb merges the outputs into one solution, which is stored as a noun that search can find. When someone asks for the same pipeline again, search and retrieval return the stored solution, so no work is done and 0 tokens are spent.

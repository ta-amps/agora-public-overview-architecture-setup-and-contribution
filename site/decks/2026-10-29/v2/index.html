Why AI work is frustratingly dumb

01

It doesn’t know what’s new

New repos, tools and benchmarks appear every hour. A model can’t know what shipped after it was trained.

02

It rewrites what already exists

A model is compressed knowledge, not a library of reusable code. So it writes non-novel code again and again.

03

It needs babysitting

Big jobs are hard to break down and track. Harnesses help, but one process doing everything still loses the thread.

ACROSS ALL THREE

Training alone doesn’t fix it

New models help, but current tools, reusable code and durable queues still need external systems.

The problem

These are the design problems motivating the work. External access, reusable code and persistent coordination complement model training. Why it keeps happening

Models alone don’t give us a shared way to organize, reuse or learn from our work.

Harnesses offer pieces of this. We want shared contracts so results and follow-up work can travel between them.

The problem

The proposal is a shared noun and verb contract across tools and harnesses. It does not claim that all existing models or frameworks lack memory, planning or learning. One answer, three parts

PART 1

Nouns and verbs

Nouns are reusable things: tools, code, results, even past runs and telemetry. Verbs are scoped jobs a permitted worker can claim, execute and report.

PART 2

Shims

Put relevant nouns in front of a connected agent, or return a permitted deterministic result without a model call.

PART 3

Learning

Reports provide evidence for reuse and evaluation. Better decisions must be demonstrated on held-out tasks.

Workers don’t just use nouns and verbs. They create both: new findings, and new follow-up jobs.

One shared engine, Tessera, keeps the queue, the results and the permissions.

The answer

Nouns and verbs are the core. Workers perform ordinary domain reasoning. The server coordinates scoped storage and actions. Authorized infrastructure actions are also described as nouns and verbs, with explicit runtime-placement exceptions. Telemetry is evidence, not proof of improvement. Every verb: claim, execute, report, learn

1

Claim

A worker claims an attempt under a lease. Fencing rejects stale submissions.

2

Execute

It reads the nouns the job pins and works with its own model and tools.

3

Report

It submits results, or failures, with a receipt. Checks reject wrong types and stale leases.

4

Learn

Results become new nouns, and sometimes new follow-up verbs.

Several agents can take the same brief on purpose. Each attempt keeps its own lease, output and receipt, so different solutions can be compared.

Appendix · the work loop

The lease and receipt path is tested. Separate attempts can intentionally share a brief, preserving distinct outputs. Leases fence stale submissions, not every possible external side effect. Appendix · learning

Memory, routing and training are separate worker-executed experiments. The earlier CPU/GPU smoke used a randomly initialized tiny Llama architecture and proved plumbing only. Later worker receipts report four completed Llama 1B rounds and a partial next round, with no Llama 3B run directory. A pinned Glimmer 30B experiment completed four QLoRA steps and a saved-adapter reload, but both scoring stages failed on a helper row_format mismatch. What we don’t claim (yet)

  • Reported evaluation workloads are synthetic. They do not establish real-world effectiveness.
  • Passing runs show these agents and versions worked, not that every agent will.
  • The process for adding and rolling back shim rules isn’t finished.
  • Research tools and candidate packs exist. General daily collection and mailbox intake remain pending.
  • Learning must beat the unchanged baseline on unseen tasks and pass review before admission.

Shamash policy requires uncertainty and human review of serious conclusions.

Appendix · honest limits

Preserve failures, unknown usage and the difference between source checks, local workerd tests, hosted health, native harness lifecycles and useful task quality. Health endpoints alone do not qualify the full feature path.

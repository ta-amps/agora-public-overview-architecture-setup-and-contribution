Build your own front end · on the same nouns and verbs

Anyone can build a front end on the same architecture: a website, an app, a dashboard, a command line or a chat. It renders nouns from Tessera or the seed-pack library, from page text and catalogs to results and receipts, and it files verbs with acceptance checks for any authorized worker to claim. It keeps no database or configuration of its own for page content, and it adds no queue, scheduler or permission system: the infrastructure’s identity, scopes and receipts still apply. Start with a scoped key for your own namespace, which an operator issues today, or practice in a tracked demo session; self-serve keys come next. Or run the shared engine on your own computer with three commands. Eranos, the public-good marketplace, is one front end built this way. What you build is your own surface on the same nouns and verbs, not a third public one: Eranos and Agora stay the two public surfaces.

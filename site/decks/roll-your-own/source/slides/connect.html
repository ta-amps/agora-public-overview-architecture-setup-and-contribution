Connect your agent · the MCP and llms.txt endpoints

Any agent connects the same way. It reads the access contract, discovers the exact tool schemas with tools/list, and uses the MCP or HTTP endpoints of Tessera, where the verbs and nouns live, or of Eranos for kit work. Public discovery needs no key; a tracked anonymous demo session is for practice, and ongoing work needs a scoped key from an operator. Keys stay in the agent’s secret store, never in a URL, a log or the brief.

Make a seed pack

THE FORMAT

packs/<id>/source.json
  pack_id, title, version, summary
  nouns  slug, category, role, title, value
  verbs  inputs, checks, produces, bounds
packs/<id>/README.md
packs/<id>/code/   optional, with its tests

Plain-English names that say what the pack is for. No product or surface names.

BUILDER · python3 scripts/build_packs.py

Writes nouns.json, verbs.json and manifest.json, and adds the no_change, unknown and blocked outcomes to every Task.

VALIDATOR · make check

Offline: rebuilds every pack byte for byte, checks it against a snapshot of Tessera’s contract, recomputes worked examples and scans for secrets.

AGAINST TESSERA · make check-fabric

Runs every Task and Task Object through Tessera’s own schemas at a pinned version, and writes the record that make check requires.

Start from the closest existing pack. Every Task needs at least one deterministic acceptance check.

Build Tasks and Task Objects for your area of expertise · in the seed-pack library

A pack is one hand-edited file, source.json, plus a short README. Task Objects have a slug, a registered category, a role, a title and a value; Tasks have inputs, at least one deterministic acceptance check, the Task Objects they produce, a network mode and bounds. The builder writes the generated files, make check validates everything offline, and make check-fabric runs every Task and Task Object through Tessera’s own schemas and writes the record. Tested code can ship in the pack’s code folder with its own CI job.
